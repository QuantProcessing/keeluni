# 使用终端

## 交易页

```
┌ 顶栏：KeelUni · 交易 · 对冲 · 更多 ─────────────────── 账户汇总 · 会话菜单 ┐
├ 行情头（标的选择 + 价格/标记价/24h/资金费率） ┬ 盘口/成交 ┬ 下单面板 ─────┤
├ K 线（画线工具）                              │           │              │
├ 资产 · 持仓 · 当前委托 · 成交记录（全部账户）  ┤           │ 账户概览     │
└ 状态栏 ──────────────────────────────────────────────────────────────────┘
```

### 选择标的

点击标的名称或按 <kbd>⌘K</kbd> 打开市场列表。可按交易所、永续/现货筛选，「可交易」标签只列出已连接账户能交易的市场；可交易的市场在交易所名后有一个绿点，悬停可看到是哪些账户。

所有市场都可以看行情，与是否有账户无关：**行情永远来自订单簿所在交易所**。

### 选择账户

下单面板顶部是「账户」行：

- 只有一个账户能交易当前标的时，直接显示该账户。
- 有多个时（例如 Binance 原生账户和 Gate CrossEx 都能交易 Binance BTC 永续），点击展开列表，每个账户显示类型（原生 / 跨所保证金）和可用金额。选择会按交易所记住。
- 没有账户能交易时，面板说明原因，并提供「连接该交易所」和（如适用）「连接 Gate CrossEx」按钮。

系统**从不在背后切换账户**：账户决定用谁的钱，只能由你选择。

### 下单

- **市价 / 限价**，数量可按币或按计价货币输入，滑块按可用余额的百分比填入。
- **数量步长、最小数量、最小金额来自所选账户的规则**：经 Gate CrossEx 交易时，规则是 CrossEx 的（可能比交易所原生更细），面板会显示「最小下单」。
- 限价单可选有效方式：GTC、IOC、只做 Maker。永续可勾选「只减仓」。
- 杠杆按钮打开「调整杠杆」，会真的修改交易所上的杠杆。

下单后的提示：

| 提示 | 含义 |
|---|---|
| 已成交 / 已挂单 | 交易所已接受 |
| 已受理 · 等待交易所确认 | 经纪账户（CrossEx）已受理，交易所尚未确认；之后仍可能被拒 |
| 订单被拒 | 交易所拒绝，显示交易所原文 |
| 订单结果未知 | 网络或交易所未给出明确结果；系统会按 clientOrderId 查询，**不会重复下单** |

### 持仓与委托

底部表格汇总**所有账户**；多个账户时有「账户」列，右上角可筛选单个账户。

- 持仓的「平仓 · 市价」总是在**持有该仓位的账户**上平仓。
- 属于对冲腿的仓位标为「对冲 · 组名」。在这里平仓不会被阻止，但确认框会提示：另一条腿会单独留下，对冲组将被标记为未对冲。
- 交易所风控引擎下的订单（强平、自动减仓、下架结算）会单独标出，并弹出提示。

### 账户概览

下单面板下方显示当前账户：原生账户显示稳定币余额、可用、未实现盈亏；Gate CrossEx 显示整个保证金池（保证金余额、可用保证金、初始/维持保证金率、各交易所权益与占用），保证金率触及阈值时给出警告。

## 对冲页

对冲页面向**资金费率套利**：在一个交易所做多永续、另一个交易所做空，赚两边资金费率的差。按"找组合 → 判断 → 开仓 → 管理"的顺序排布。

```
┌ 组合栏：[做多] 标的 ▾ ⇄ [做空] 标的 ▾ ··· 入场价差 · 净资金费率 · 7 日 ┬ 下单 ┐
├ 走势（价差 / 净资金费率）         ┬ 价差深度（或两边盘口）            ┤ 4 步   │
├ 套利机会 · 对冲 · 历史                                              ┤ 资金   │
```

### 找组合：套利机会

底部第一个标签页（没有持仓时默认打开）。每个在两个以上交易所上市的币，做空资金费率最高的、做多最低的，按净年化排序；列出基差、较浅一腿的持仓量（深度）和下次结算时间。

- **深度**过滤（默认 ≥10M 美元）：没人交易的市场，费率再高也做不了。Binance 和 Hyperliquid 不批量提供持仓量，含它们的组合按另一条腿过滤。
- **已连接交易所**：只看两边都已连接账户的组合。
- 点一行，把这对标的带到页面上（已选的账户保留）。

费率每次结算都会变，开仓前看组合栏的 **7 日净资金费率**，一次性的尖峰不是可持续的收益。

### 判断：价差深度

把两条腿看成一个市场：1K、10K、50K、100K、500K 每腿金额下，按两边盘口逐档算出

- **开仓价差**：买做多腿卖盘、卖做空腿买盘的价差（bps）；
- **平仓价差**：反向；
- **往返成本** = 平仓 − 开仓，两次穿越两边盘口的成本；
- **回本**：按当前净资金费率赚回往返成本的天数；盘口不够时显示"盘口不足"。

点一行把金额填入下单。未含手续费。点右上角"盘口"可看两边原始盘口。

### 开一个对冲

1. 选方式：**双边市价**，或**限价 + 对冲**（一条腿挂单，每成交一部分另一条腿立刻市价对冲）。
2. 输入**每腿金额**，或拖动滑块按两条腿能承载的比例下单。
3. 看四个数：入场价差、净资金费率、回本时间、所需保证金 / 可用。保证金不足时按钮不可点，原因以红字写在按钮下。
4. 开仓。

按钮下方是两条腿的账户（**没有默认值**，需逐腿选择）和杠杆；没有账户时直接给出"连接 Bitget · Gate CrossEx"。**高级**里是单腿失败时的策略（回退另一条腿 / 保留并提醒）、只做 Maker、备注。两条腿用同一个 Gate CrossEx 账户时共享一个保证金池。

### 管理对冲

| 状态 | 含义 | 可做的操作 |
|---|---|---|
| 开仓中 / 平仓中 | 有动作在执行 | 限价动作可撤单 |
| 已对冲 | 两腿匹配 | 平仓（按比例，市价或限价）、全平 |
| 未对冲 | 两腿不匹配，有方向敞口 | 补腿、减腿、全平 |
| 已平仓 / 失败 | 结束 | 在「历史」中查看 |

「未对冲」的来源：开/平仓时一条腿失败，或与交易所对账发现交易所持仓少于对冲记录（在交易页手动平了、被强平、自动减仓）。展开对冲行可以看到原因、两条腿的明细、全部订单（含滑点）、日志与资金费记录。

## 期权页

布局与交易页一致：左边期权链，中间选中期权的盘口与收益曲线，右边下单。单个期权下单是默认操作，组合是进阶模式。

- **选择市场**：点左上角"BTC 期权 ▾"，先选交易所（Deribit、OKX），再选标的与结算方式（币本位 / U 本位），列表里有指数与近月平值 IV。旁边是当前到期日的指数、远期、平值 IV、25Δ 风险逆转与蝶式；下面一排是所有到期日（剩余天数与平值 IV）。
- **T 型报价**：左看涨、右看跌，中间行权价；远期处有一条青色线。右上角可在价格与 IV 之间切换，币本位系列还可在币与美元之间切换。
- **点击即选中，不跳转**：点期权链上任意一格选中该期权（整半行高亮）；点买价同时选"卖出"，点卖价选"买入"。中间一栏随之显示该期权的实时报价与希腊值、带每档 IV 的盘口（点某档价格填入下单），以及**正在填写的这笔订单**的收益曲线（到期实线、今日虚线、最大收益 / 亏损、盈亏平衡点）。
- **单腿下单**：买 / 卖，按价格或按 IV 定价（IV 按该到期日的模型换算成权利金并对齐最小变动价位），数量以标的计，GTC / 只做 Maker / IOC。下方显示支付或收取的权利金与本单 Delta。卖出未持有的期权即开空仓。
- **组合（进阶）**：右上角切到"组合"，或在单腿面板点"+ 加入组合"把当前期权带进去。此时点买价加空头腿、点卖价加多头腿；也可从"策略模板"下拉选跨式、宽跨、价差、风险逆转、蝶式、铁鹰、日历（按 Delta 选行权价），"做多 / 做空"翻转整个结构。中间的收益曲线换成整个组合的；每条腿是独立的限价单，组合可能部分成交。
- **底部**：当前委托、成交记录（点击一行选中该期权）、持仓、按到期日、情景分析（标的 × IV 网格，可推移 1 天或 7 天）、执行记录、波动率（微笑与期限结构）。持仓的"平仓"会选中该期权并把反向与数量填入单腿面板。"对冲 Delta"在所选账户的永续上生成把 Delta 压到零的市价单，确认后发送。
