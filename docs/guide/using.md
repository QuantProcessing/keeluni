# 使用终端

## 交易页

```
┌ 顶栏：KeelUni · 交易 · 对冲 · 更多 ─────────────────── 账户汇总 · 会话菜单 ┐
├ 行情头（标的选择 + 价格/标记价/24h/资金费率） ┬ 盘口/成交 ┬ 下单面板 ─────┤
├ K 线（画线工具）                              │           │              │
├ 资产 · 持仓 · 当前委托 · 成交记录（全部账户）  ┤           │ 账户概览     │
└ 状态栏 ──────────────────────────────────────────────────────────────────┘
```

### 选择标的

点击标的名称或按 <kbd>⌘K</kbd> 打开市场列表。可按交易所、永续/现货筛选，「可交易」标签只列出已连接账户能交易的市场；可交易的市场在交易所名后有一个绿点，悬停可看到是哪些账户。

所有市场都可以看行情，与是否有账户无关：**行情永远来自订单簿所在交易所**。

### 选择账户

下单面板顶部是「账户」行：

- 只有一个账户能交易当前标的时，直接显示该账户。
- 有多个时（例如 Binance 原生账户和 Gate CrossEx 都能交易 Binance BTC 永续），点击展开列表，每个账户显示类型（原生 / 跨所保证金）和可用金额。选择会按交易所记住。
- 没有账户能交易时，面板说明原因，并提供「连接该交易所」和（如适用）「连接 Gate CrossEx」按钮。

系统**从不在背后切换账户**：账户决定用谁的钱，只能由你选择。

### 下单

- **市价 / 限价**，数量可按币或按计价货币输入，滑块按可用余额的百分比填入。
- **数量步长、最小数量、最小金额来自所选账户的规则**：经 Gate CrossEx 交易时，规则是 CrossEx 的（可能比交易所原生更细），面板会显示「最小下单」。
- 限价单可选有效方式：GTC、IOC、只做 Maker。永续可勾选「只减仓」。
- 杠杆按钮打开「调整杠杆」，会真的修改交易所上的杠杆。

下单后的提示：

| 提示 | 含义 |
|---|---|
| 已成交 / 已挂单 | 交易所已接受 |
| 已受理 · 等待交易所确认 | 经纪账户（CrossEx）已受理，交易所尚未确认；之后仍可能被拒 |
| 订单被拒 | 交易所拒绝，显示交易所原文 |
| 订单结果未知 | 网络或交易所未给出明确结果；系统会按 clientOrderId 查询，**不会重复下单** |

### 持仓与委托

底部表格汇总**所有账户**；多个账户时有「账户」列，右上角可筛选单个账户。

- 持仓的「平仓 · 市价」总是在**持有该仓位的账户**上平仓。
- 属于对冲腿的仓位标为「对冲 · 组名」。在这里平仓不会被阻止，但确认框会提示：另一条腿会单独留下，对冲组将被标记为未对冲。
- 交易所风控引擎下的订单（强平、自动减仓、下架结算）会单独标出，并弹出提示。

### 账户概览

下单面板下方显示当前账户：原生账户显示稳定币余额、可用、未实现盈亏；Gate CrossEx 显示整个保证金池（保证金余额、可用保证金、初始/维持保证金率、各交易所权益与占用），保证金率触及阈值时给出警告。

## 对冲页

对冲把两条腿（一多一空）作为一个仓位来开、管、平。

```
┌ 组合栏：做多 [标的 ▾] ⇄ 做空 [标的 ▾] ··· 入场价差 · 比例 · 净资金费率 · 7 日 ┬ 下单 ┐
├ 价差图（价差 / 净资金费率）           ┬ 腿 1 盘口 ┬ 腿 2 盘口 ┤ 腿与账户 │
├ 对冲列表（可展开查看两条腿、订单、日志、资金费、备注）           ┤ 资金   │
```

### 开一个对冲

1. 在组合栏选两条腿的标的；**两条腿总是一多一空**，⇄ 交换多空（现货腿只能做多）。
2. 看价差图判断入场时机：价差 = 腿 2 相对腿 1（bps），底层不同时显示价格比；「净资金费率」标签页显示两腿资金费率的历史。
3. 在右侧选择方式：
   - **双边市价**：两条腿同时市价成交。
   - **限价 + 对冲**：一条腿挂限价单，每成交一部分，另一条腿立刻用市价单对冲。「只做 Maker」只作用于挂单那条腿。
4. 输入数量（每条腿的金额，或腿 1 的币数量）。
5. 为每条腿选择账户（**没有默认值**）。账户旁的杠杆按钮显示用于估算保证金的杠杆：在此设置的，或该账户现有仓位的，否则按 1 倍。
6. 查看预览：每条腿的数量、预计成交价、滑点、金额；入场价差、数量偏差、吃单成本、净资金费率、回本时间、**所需保证金 / 可用**。保证金不足时按钮不可点。
7. 选择单腿失败时的策略：**回退另一条腿**（默认）或**保留并提醒**。

两条腿用同一个 Gate CrossEx 账户时，它们共享一个保证金池，可用保证金只算一次。

### 管理对冲

| 状态 | 含义 | 可做的操作 |
|---|---|---|
| 开仓中 / 平仓中 | 有动作在执行 | 限价动作可撤单 |
| 已对冲 | 两腿匹配 | 平仓（按比例，市价或限价）、全平 |
| 未对冲 | 两腿不匹配，有方向敞口 | 补腿、减腿、全平 |
| 已平仓 / 失败 | 结束 | 在「历史」中查看 |

「未对冲」的来源：开/平仓时一条腿失败，或与交易所对账发现交易所持仓少于对冲记录（在交易页手动平了、被强平、自动减仓）。展开对冲行可以看到原因、两条腿的明细、全部订单（含滑点）、日志与资金费记录。
