# KeelUni 是什么

KeelUni 是一个**自托管、单人使用**的一站式交易系统：在自己的机器上运行，连接你在各个交易所的账户，用一个终端完成看盘、下单、管理仓位和对冲。

名字由两部分组成：

- **Keel（龙骨）**：船底那根纵贯的脊梁，让船在风浪里保持平稳。对应系统最看重的事：下单安全、状态可信、出错时可解释。
- **Uni（统一）**：一个入口包罗所有市场。今天是永续与现货，之后会扩展到期权、大宗商品等。

## 能做什么

| 能力 | 说明 |
|---|---|
| 交易 | 在任意已连接的交易所下市价/限价单、设置杠杆、平仓；同一个标的可以用不同账户交易 |
| 多账户 | 原生账户（一个交易所一套 API Key）与经纪账户（Gate CrossEx：一套 Key、一个保证金池、多个交易所）并存 |
| 行情 | K 线（含画线工具）、盘口、逐笔成交、标记价、资金费率与倒计时，全部来自订单簿所在交易所的原生接口 |
| 对冲 | 两条腿作为一个仓位开仓、平仓、补腿、减腿；价差与净资金费率走势图；保证金检查 |
| 资金费率 | 所有永续的当前费率、结算周期、年化与历史，跨交易所可比 |

## 系统由什么组成

```
浏览器 ── web（React 终端）
            │ 同源 cookie 会话
          trader   登录、会话、反向代理、提供前端      —— 无数据库
            │ bearer token，仅内网
          hedger   对冲应用：两条腿作为一个仓位         —— 自己的 PostgreSQL
            │ bearer token
          gateway  与交易所无关的 REST + WebSocket API —— 只有一个加密文件
            │
          exchange 规范化的客户端与模型
            │
          sdk      各交易所原生 API
```

每一层只做自己的事，详见[总览与分层](/architecture/)。

## 不做什么

- **不托管资金、不做撮合**：订单进入交易所真实的订单簿，交易所是唯一事实来源。
- **不保存订单账本**：gateway 只持有可从交易所重建的当前事实；需要积累的数据（如对冲记录）属于拥有自己数据库的应用。
- **不替你切换账户**：同一标的有多个账户可交易时，由你选择；系统记住选择，但从不在背后换成另一个账户。
- **不修改交易所的账户模式、持仓模式、保证金模式**：只读取并遵守它们。

::: warning 风险提示
每一笔订单都会进入真实交易所。请使用**没有提现权限**的 API Key，并从小额开始。
:::
