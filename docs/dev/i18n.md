# 国际化

界面默认中文，可在会话菜单切换为英文，选择保存在浏览器（`keeluni.lang`）。

## 前端字典

```
web/src/i18n/
  index.tsx   语言状态、translate、useT、Interpolate、useHedgerText
  en.ts       英文字典：定义全部键
  zh.ts       中文字典：类型为 Messages，必须翻译每一个键
  hedger.ts   hedger 编码文本的中英文格式与渲染
```

### 添加一条文字

1. 在 `en.ts` 中添加键与英文；
2. 在 `zh.ts` 中添加同一个键的中文——**漏掉会导致类型检查失败**；
3. 在组件中使用：

```tsx
const t = useT();
<span>{t("ticket.minSizeIs", { min: rules.minQty })}</span>
```

组件外（工具函数、回调中的提示）使用 `translate(key, params)`，它读取当前语言。

### 占位符与复数

- 值中的 `{name}` 由参数替换；
- 需要逻辑（英文复数、语序）时，值可以是函数：

```ts
"accounts.count": ((p) => `${p.n} ${Number(p.n) === 1 ? "Account" : "Accounts"}`) as Fn,   // en
"accounts.count": (p) => `${p.n} 个账户`,                                                  // zh
```

- 占位符是元素（链接、代码）时用 `Interpolate`：

```tsx
<Interpolate text={t("login.footer")} values={{ command: <code>trader passwd</code> }} />
```

### 测试保证

`web/src/i18n/i18n.test.ts` 检查：

- 两份字典的键完全一致，占位符一致；
- 中文值与英文值不同（名称、代码等少数例外列在白名单中）。

### 术语

与主流中文交易所一致：

| 英文 | 中文 |
|---|---|
| Perp / Spot | 永续 / 现货 |
| Funding rate | 资金费率 |
| Mark price / Index price | 标记价格 / 指数价格 |
| Liquidation price | 强平价格 |
| Reduce only / Post only | 只减仓 / 只做 Maker |
| Cross | 全仓 |
| Open orders / Trade history | 当前委托 / 成交记录 |
| Unhedged | 未对冲 |
| Rehedge / Trim / Unwind | 补腿 / 减腿 / 全平 |

**不翻译**：交易所名称、标的 symbol、交易所返回的拒单原文、clientOrderId 等标识。数字保持 `82,817.3` 的分组格式；时间 `MM/DD HH:mm:ss`；K 线坐标轴跟随语言。

## hedger 的消息

hedger 的日志、组的问题、动作与订单的错误、开仓预检问题、请求被拒，都以**编码文本**传递（`pairexec/text.go`）：

```go
textOf("event.makerFilled", "leg", 1, "filled", "0.004", "target", "0.01")
withReason(textOf("failure.hedgeRejected", "leg", 2), venueText("Insufficient margin (-2019)"))
```

- `textOf(code, 参数…)`：编码 + 参数，同时生成英文渲染（`Message`）；
- `withReason(text, reason)`：附加原因（编码文本或交易所原文）；
- `joinTexts(a, b)`：后接另一条；
- `venueText(s)`：交易所或 gateway 的原文，没有编码，任何语言都原样显示；
- 拒绝请求用 `invalid(code, 参数…)`，响应体带 `error.text`。

数据库中以 JSON 存储（复用原有的文本列）；改造之前写入的纯字符串读出时作为没有编码的文本，照常显示。

前端 `web/src/i18n/hedger.ts` 为每个编码提供中英文格式，并翻译作为参数传入的词（方向、订单状态、动作、角色、组状态、风控来源）。未知编码（更新的 hedger）退回到英文 `message`。

### 添加一个 hedger 编码

1. 在 `pairexec/text.go` 的 `textFormats` 中加入编码与英文格式；
2. 在 `web/src/i18n/hedger.ts` 的 `en`（与 Go 完全一致）和 `zh` 中加入；
3. 测试会读取 `pairexec/text.go`，检查每个编码在前端两种语言中都存在、英文完全一致、占位符一致。
